README for Code and Data Submission
Data and R codes that support the findings of this study are available at GitHub (https://github.com/academicqkk/mycorrhizal.git)
---------------------------------------------------------------
1. Description
---------------------------------------------------------------
This repository contains the code and data used to reproduce the
analyses and figures presented in the manuscript. All scripts,
datasets, and instructions are provided to ensure transparency
and reproducibility.

4. Data Documentation
---------------------------------------------------------------
Data files include:
	Arbuscularmycorrhizalforests_dataset.csv, Ectomycorrhizalforests_dataset.csv, Mixedmycorrhizalforests_dataset.csv: [Arbuscular mycorrhizal forests, Ectomycorrhizal forests, and Mixed mycorrhizal forests (Mixed ectomycorrhizal and arbuscular mycorrhizal forests). These datasets include the following variables:
- plot_ID: Plot identifier (unique ID for each plot)
- year: Year of survey or measurement
- LON: Longitude (decimal degrees)
- LAT: Latitude (decimal degrees)
- ECOSUBCD: Ecological region code
- ELEV: Elevation (meters above sea level)
- species_richness: Species richness (number of species per ha)
- SLOPE: Slope (degrees)
- STDAGE: Stand age (years)
- EcM_percentage: Percentage of basal area from ectomycorrhizal (EcM) species
- Rs: Resistance index
- Le: Recovery index
- pre: Precipitation (mm)
- tem: Mean temperature (°C)
- clay: Soil clay fraction (%)
- bulk: Soil bulk density (g/cm³)
- totaln: Total nitrogen content (g/kg)
- ph: Soil pH
- Mycorrhizal.type: Dominant mycorrhizal type (e.g., EcM, AM, Mixed)]
	monospecificforests_pairedcomparisons.csv, Arbuscularmycorrhizalmonospecificforests_dataset.csv and Ectomycorrhizalmonospecificforests_dataset.csv: [Arbuscular mycorrhizal monospecific forests and Ectomycorrhizal monospecific forests. These datasets include the following variables.
- ECOSUBCD: Ecological region code
- Rs_log_mean: Mean value of resistance (log-transformed)
- Rs_log_sd: Standard deviation of resistance (log-transformed)
- Le_log_mean: Mean value of recovery (log-transformed)
- Le_log_sd: Standard deviation of recovery (log-transformed)
- row_count: Row index (row number in the dataset)]
	INVYREcMpercentagechange.csv: [changes in the percentage of EcM (ectomycorrhizal) forest communities across U.S. ecoregions over the past two decades. 
- ECOSUBCD: Ecological region code
- max_INVYR_percentage: Recent EcM percentage (%)
- min_INVYR_percentage: Initial EcM percentage (%)
- chage_percentage: Difference between recent and initial percentages]
	Ectomycorrhizalpercentagechangesummarybyecoregion_dataset: [Changes in ectomycorrhizal (EcM) percentage across ecoregions.]
	significant decline in EcM percentage across U.S. ecoregions.tiff: [Changes in EcM percentage of forest communities during the past two decades across ecoregions of the United States. The proportion of plots within each region experiencing a decline in EcM percentage]
	monospecificforests_Arbuscularmycorrhizal versus Ectomycorrhizal resistance.tiff: [Comparison of resistance of monospecific forests composed of arbuscular mycorrhizal (AM) tree species versus monospecific forests composed of ectomycorrhizal (EcM) tree species.]
	monospecificforests_Arbuscularmycorrhizal versus Ectomycorrhizal recovery.tiff: [Comparison of recovery of monospecific forests composed of arbuscular mycorrhizal (AM) tree species versus monospecific forests composed of ectomycorrhizal (EcM) tree species.]

If external data sources are required:
[CRU temperature and precipitation data can be accessed at https://crudata.uea.ac.uk. 
WorldClim climate data is available at https://www.worldclim.org. 
SoilGrids soil properties data is provided by ISRIC and can be accessed at https://www.isric.org. 
MODIS Normalized Difference Vegetation Index (NDVI) products are accessible at https://ladsweb.modaps.eosdis.nasa.gov. 
Forest Inventory and Analysis data from the U.S. Department of Agriculture Forest Service is available at https://research.fs.usda.gov.]
